## 🛠️ How to Run & Deploy

```bash
# Start local dev server:
npm run dev:client
# Runs on http://localhost:5173

# Or build for production:
npm run build
```

You can deploy the `dist/` folder for free in seconds to **Vercel**, **Netlify**, or **GitHub Pages**, and send the link directly to Carter in a YouTube Short / TikTok tag (`@carterpcs`)!
