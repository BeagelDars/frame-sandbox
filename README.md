# Frame — Minimalist Visual Website Builder for Non-Coders

A distraction-free, block-based website builder designed for non-coders to create and share their own clean websites with instant unique URLs.

## Features

- **No Code Required**: Build full websites by adding simple, configurable content blocks:
  - **Profile Header**: Avatar/badge, full name, role headline, bio, and alignment.
  - **Photos & Visuals**: Images with aspect ratios (16:9, 4:3, 1:1, natural) and captions.
  - **Link Hub**: Interactive stack of clean link buttons with titles and subtitles.
  - **Project & Feature Cards**: Cards with cover images, titles, descriptions, and links.
  - **Text & Headings**: Section headings, paragraphs, and callout blocks.
  - **Quote / Highlight**: Editorial quotations with author and publication attribution.
  - **FAQ / Accordion**: Collapsible Q&A pairs.
  - **Social & Contact Bar**: Clean SVG pills for Email, X/Twitter, GitHub, LinkedIn, Instagram, and Website.
  - **Dividers & Spacing**: Minimalist separation lines, dot clusters, and custom whitespace.
- **Minimalist Light Palettes**: Pure White, Warm Linen, Soft Stone, and Pale Slate with Swiss Sans, Editorial Serif, and Monospace typography.
- **Instant Live Preview**: Real-time split preview with Desktop, Tablet, and Mobile viewport frames.
- **1-Click Publishing & Unique URLs**: Generates unique short links (e.g. `/s/ftuycev`) that render full-screen websites with an unobtrusive "Fork in Sandbox" button.
- **Export to HTML**: Download self-contained `index.html` file in one click.
- **Starter Templates**: Curated templates (Personal Bio, Photography & Portfolio, Product Launch, Blank Canvas) with **zero emojis** and clean typography.

## Quick Start

```bash
# Start development mode
npm run dev

# Or run the production build
npm start
```

Open [http://localhost:3001](http://localhost:3001) in your browser.
